Titanic - предсказание выживаемости пассажиров

```python
Мой первый сквозной проект по табличному ML на базе классического соревнования [Titanic с Kaggle](https://www.kaggle.com/competitions/titanic). 
```

# Что лежит в репозитории

```python
- `notebooks/eda.ipynb` - разведочный анализ данных, графики и проверка базовых гипотез.
- `notebooks/model.ipynb` - генерация новых признаков, сборка пайплайнов предобработки, сравнение моделей и подготовка файла для Kaggle.
- `requirements.txt` - список библиотек, на которых всё запускалось.
- Папка `data/` с исходными таблицами и сабмитом в `.gitignore`, чтобы не тащить датасеты в Git.
```

# Что делал и к чему пришел

```python
### 1. Разведочный анализ (`eda.ipynb`)
Посмотрел на распределения и пропуски. Главные закономерности ожидаемые, но на цифрах видны очень четко: женщины и дети до 6 лет выживали заметно чаще, а вот у мужчин из 3-го класса шансов почти не было. Много пропусков оказалось в возрасте (`Age`) и каютах (`Cabin`) - каюты решил не использовать из-за слишком большого числа пустых значений, а возраст аккуратно восстанавливать.
```

### 2. Работа с признаками (`model.ipynb`)
Чтобы помочь моделям, вытащил из данных несколько дополнительных фичей:
- `Title` - достал обращения из имен (`Mr`, `Mrs`, `Miss`, `Master`, редкие титулы объединил в `Rare`). По ним же заполнил пропуски в возрасте медианным значением по каждой группе (медианы считал строго на `train`, чтобы не было утечки данных).
- `FamilySize` и `IsAlone` - общий размер семьи на борту (`SibSp + Parch + 1`) и флаг, плыл ли человек один.
- `IsChild` - бинарный признак для детей до 6 лет включительно.
- `Sex_Pclass` - пересечение пола и класса каюты, чтобы линейным моделям было проще разделять группы вроде «женщина 1-го класса» и «мужчина 3-го класса».


### 3. Модели и валидация
Всю предобработку (`SimpleImputer`, `StandardScaler`, `OneHotEncoder`) завернул в `ColumnTransformer` и `Pipeline`. Качество проверял на стратифицированной кросс-валидации по 5 фолдам (`Accuracy`):
- `LogisticRegression` (бейзлайн): **0.8373 +- 0.0118**
- `RandomForestClassifier`: **0.8339 +- 0.0129**
- `GradientBoostingClassifier`: **~0.838**


### 4. Результат на Kaggle
В итоге для финального прогноза взял `GradientBoostingClassifier`, обучил на всей тренировочной выборке и сгенерировал `submission.csv` (418 предсказаний, доля выживших получилась `0.342`).

```python
Публичный скор на лидерборде Kaggle: **0.77272**. Просадка относительно кросс-валидации для «Титаника» ожидаемая: тестовая выборка небольшая, и бустинг на 150 деревьях сильнее подстроился под локальные особенности `train`.
```
